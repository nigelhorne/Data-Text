   37: =head1 DESCRIPTION
   38: 
   39: C<Data::Text> provides an object-oriented interface for managing and manipulating text content in Perl.
   40: It wraps string operations in a class-based structure,
   41: enabling clean chaining of methods like appending, trimming, replacing words, and joining text with conjunctions.
   42: It supports flexible input types,
   43: including strings, arrays, and other C<Data::Text> objects,
   44: and overloads common operators to allow intuitive comparisons and stringification.
   45: 
   46: =head1 SYNOPSIS
   47: 
   48:     use Data::Text;
   49: 
   50:     my $d = Data::Text->new("Hello, World!\n");
   51: 
   52:     print $d->as_string();
   53:
